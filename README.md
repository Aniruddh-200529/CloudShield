# CloudShield

CloudShield is a web-based platform that combines probe-based cloud infrastructure monitoring with identity-aware access management.

## Core Components

- Infrastructure Monitoring Probes
- Cloud Infrastructure Monitoring
- Identity and Access Management
- Role-Based Access Control
- Multi-Factor Authentication
- Audit Logging
- Event Correlation
- Security and Infrastructure Alerts
- Centralized Monitoring Dashboard
